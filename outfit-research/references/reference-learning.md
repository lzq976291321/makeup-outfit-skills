# 从参考图积累穿搭与配饰风格

识别“研究这套穿搭”“这对耳环好看，沉淀一下”“提炼项链与领口的搭配”“把美甲也记录下来”等任务。分析请求只交付观察与方案；明确要求更新 Skill 时才写入案例。生成和对外推送不因分析任务自动执行。

## 观察与提炼

1. 记录图片来源说明和用户关注对象；区分已看见、遮挡和不确定部分，不猜品牌、材质成分或购买价格。
2. 观察衣服轮廓、肩线、领口、长短层次、颜色面积、纹理与受力；把人物体型、姿势、镜头和服装本身的作用分开。
3. 耳环：轮廓、尺寸相对耳垂与下颌的比例、金属色、表面反射、垂坠与发丝遮挡。项链：链条粗细、长度落点、吊坠尺度、叠戴间距、与领口的关系及锁骨处接触。
4. 戒指、手链与美甲：记录数量、位置、甲型与长度、颜色、透明度、亮片及装饰尺度、彼此反光与配色关系。美甲的妆面配方和细节修复由妆容 Skill 深入处理；穿搭侧保留协调所需信息。包、鞋、腰带与发饰同样按尺度、位置和材质观察。
5. 提炼可替换的关系，例如“领口留白承接短项链，小耳环不挤占下颌轮廓”“细闪美甲呼应银饰，衣服承担哑光大色块”。强装饰风格也可成立，不能把简约当作统一答案。
6. 给出完整组合与一次只替换一个变量的方案，明确保留的单品细节。衣服与配饰参考不负责人物身份。

## 记录与演进

- 新风格放在 `references/styles/<descriptive-slug>.md`，从本 Skill 的“风格索引”链接。先检索现有案例，同一规律以变体补充；不同风格独立保存，不覆盖旧风格。
- 单张图只能支持该图的观察与搭配假设；“已试图”和“用户认可”必须有实际结果或明确反馈。未经验证不声称跨体型或实穿效果稳定。
- 将新图的配饰作为参数，不固定为所有造型都戴相同耳环、项链或美甲。主文件只吸收反复成立或用户明确指定的判断，具体装饰留在案例里。
- 修订记录简述变动、原因、用户反馈与未解项；无须复制完整聊天。公开仓库不默认收录人物照片、本机绝对路径与私有来源链接。

## 风格卡模板

```markdown
# 风格名称
状态：仅分析 / 已试图 / 用户认可
来源与目标：无需原聊天即可理解的非敏感描述
可见观察与不确定项：服装、配饰、姿态、光线分开
组合规律：轮廓、长短、留白、颜色面积、反光节奏
服装参数：版型、领口、衣长、层次、纹理、连接结构
配饰参数：耳环、项链、戒指、手链、美甲、其他；未出现项标不适用
固定与可替换：哪些细节必须还原，哪些可换
提示词：穿搭描述、身份保持、配饰位置与接触
检查：单品结构、链条落点、耳垂连接、甲片结构、手指遮挡
反馈与修订：实际变化、用户评价、仍未验证范围
```

代表性输入：“研究这张照片的珍珠耳环和方领搭配”——只研究耳环与领口的尺度、留白和材质关系，不改脸、不擅自生成；照片缺失时先说明无法观察。
