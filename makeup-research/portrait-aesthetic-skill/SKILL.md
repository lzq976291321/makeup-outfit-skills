# AI 人像摄影：关系优先

## 输出形式
宫格仅是历史验收时便于比较的展示方式，不是 Skill 的输出约束。默认生成独立单张成片；风格卡中的多个版本是可选方案，不要求一次全部生成。只有用户当轮明确要求宫格或拼图时才采用；要求多张时默认分别交付。历史记录里的左右、A–D 与格位仅用于识别当时样片，不规定新版布局。

## 参考图与风格优先级
遵循 [妆容主流程的优先级](../SKILL.md#有参考图时的优先级)：用户明确要求优先，Skill 主导妆效与造型，身份图提供可辨识的本人特征。浓妆后的明显观感变化可以接受，不要求复制原图；只有用户指定保留项时才冻结相应造型。验收须同时满足妆效充分和本人可辨识。

## 默认完整成片
身份图只提供脸部辨识特征，Skill 主导发型、神态、动作、服装配饰、场景、构图、照明与后期，并把各项决定写入工具提示词。未指定项自主设计，不自动沿用原照；只有明确的局部改妆请求才冻结其余元素。默认任务若只完成原照换妆，判为未完成。

## 默认妆感强度
遵循[默认加强妆感](../SKILL.md#默认加强妆感)：未指定强度时使用清楚可见的完整妆面，增强眼影层次、睑缘、睫毛、腮红与唇色，并保持主次。柔和、低饱和与松弛不等于淡妆；用户明确要求淡妆或忠实还原参考强度时覆盖默认。

## 目标
将参考图拆成可以迁移的光影、色彩、材质、姿态和注意力组织方法。更换人物后保留画面的协调性。风格图不提供人物身份；身份图只提供脸部辨识特征，发型、肤色妆效与造型按目标设计。

## 妆容选择与适配
遵循[人物分析与妆容组合](../references/adaptive-makeup-design.md)，不设固定默认妆容。先分析身份图，再细化底妆、眉眼、唇颊、修容及反光模块，组合适合本人的精致妆。冷白透粉、细闪、水润唇与近轴闪光均为可选设计，不因只调用本 Skill 自动启用。用户指定该风格或分析后选中时，再读取对应配方。无身份图时先设计新成年人物的特点，不假称已看图。

## 先确定任务
区分三种输入：身份参考负责“是谁”；风格参考负责“怎么拍”；姿态参考负责“怎样摆”。同一张图可以承担多个角色，但应明确角色。只给风格图时，默认创作新的成年人物；需要保持特定人物时使用用户指定的身份图，不以文字承诺精确锁脸。没有图像输入能力时说明限制，不假称已分析。

先利用已有信息；只有身份来源、必须保留的服装或输出用途不明确且影响结果时才提问。输出比例、妆容强度等可给出明确默认值。

## 工作流
1. 查看图片，按主体、光影、色彩、妆容、动作接触、材质、构图记录观察。将可见事实与推断分开；不从照片断定真实年龄、人格、族裔或拍摄设备。
2. 提炼 3–5 条“关系规则”，并指出可替换的表面元素。首次分析本包来源图时读 [视觉分析](references/visual-analysis.md)。新参考应重新观察，不套用来源图结论。
3. 创建简短参数卡，明确身份、风格、姿态各自来源，按 [参数与模板](references/prompt-template.md) 组织提示词。
4. 选一种主光、一个主动作、一个主视觉中心。脸和手可形成主次，但不要让眼妆、首饰、背景同时争抢注意力。
5. 使用当前环境已提供且适合的图像工具；本 Skill 不假定特定 API 或插件。只要求提示词时交付提示词；要求生成时才执行生成。不要自行安装工具、调用付费外部服务或发布内容。
6. 按 [质量检查](references/quality-check.md) 检查实际结果；看不到结果则标为未检查。首次生成按完整目标设计；用户已认可成片后的局部修复才保留已通过部分，不把身份图原照视为已认可造型。

## 已验收风格：冷白透粉闪光妆

用户要求冷白底妆、淡红晕、眼周细闪、突出锁骨与皮肤时，读 [冷白透粉配方](references/porcelain-rose-flash.md)。这是可选妆面模式；仅按指定或设计选择使用，不作为通用默认。

## 必须保持的判断
- 身份优先于美化：保留眼距、眼型、鼻翼、唇形、下颌和不对称特征；不要以放大眼睛、缩鼻、削脸、未经要求提亮肤色替代摄影质感。
- 光线必须能解释脸、手、衣料、首饰和背景的明暗；局部光泽不等于全脸油亮。
- 先写清手部空间关系，再写美甲与戒指。遮挡不要求所有手指可见，但每个可见手指都应可追溯到对应手掌。
- 材质通过反光尺度、纹理与受力区别：皮肤细碎起伏、针织漫反射、金属小而亮、唇釉连续湿润反射。
- 镜头、光圈、色温数字仅可作创作意图或实拍起点；未经验证不得写成原图事实或保证模型遵循。
- 不使用“完美脸”“无瑕皮肤”等容易抹平身份与纹理的笼统词。

## 输出约定
默认中文解释；生成提示词可按工具习惯使用英文。交付：视觉关系摘要、参数卡、可直接使用的正向提示词、工具支持时的负面提示词、待检查项。用户只要其中一部分时缩减输出。

需要跨人物/场景改写时读 [完整示例](references/examples.md)。复杂手势、材质与布光的操作准则在 [摄影决策](references/photography-decisions.md)。文件包安装与范围见 [使用说明](USAGE.md)。

## 已认可的可选变体

用户要求柔雾底妆、连鼻玫粉腮红或黑底触唇近景时，可读 [玫粉柔雾黑底近景](references/rose-pink-velvet-closeup.md)。保留柔淡、浓郁两版；无图生成与一次近景身份参考两宫格获用户认可。按本人五官加强眉眼和唇部修饰，不仅叠加粉色；不成为固定默认配方。
