# AI 人像摄影：关系优先

## 参考图与风格优先级
遵循 [妆容主流程的优先级](../SKILL.md#有参考图时的优先级)：用户明确要求优先，Skill 主导妆效与造型，身份图提供可辨识的本人特征。浓妆后的明显观感变化可以接受，不要求复制原图；只有用户指定保留项时才冻结相应造型。验收须同时满足妆效充分和本人可辨识。

## 默认妆感强度
遵循[默认加强妆感](../SKILL.md#默认加强妆感)：未指定强度时使用清楚可见的完整妆面，增强眼影层次、睑缘、睫毛、腮红与唇色，并保持主次。柔和、低饱和与松弛不等于淡妆；用户明确要求淡妆或忠实还原参考强度时覆盖默认。

## 目标
将参考图拆成可以迁移的光影、色彩、材质、姿态和注意力组织方法。更换人物后保留画面的协调性。不要默认复制参考人物的五官、肤色、发型、体型或性别表达。

## 按妆效意图识别
结合用户目标、修饰对象与上下文判断，不要求固定口令，也不机械匹配单个词。
- 人物妆容、写真或皮肤修图语境中，冷白皮、冷白透粉、白里透红、瓷白底妆、布灵布灵、bling bling、眼周亮晶晶、珠光眼影、细闪妆等表达，以及意思相近的自然描述，可触发本 Skill。
- 用户未重复关键词，但在已有妆容任务中说“再闪一点”“白一点、透一点红”等，沿用该任务识别。
- “布灵布灵”若修饰珠宝、衣服、背景或其他物体，不据此触发妆容流程；泛泛的人像或写真生成请求、单独“突出锁骨”也不触发。否定表达如“不要冷白皮、不要闪片”不作为正向触发信号；若同时有明确妆容任务，则执行该任务并尊重否定约束。
- 识别到目标妆效或用户显式调用本 Skill 后，才使用以下招牌默认值。用户只指定其中某项时，优先该项，其余作为可覆盖默认；用户指定自然肤色或无闪妆时不强加冷白与细闪。

## 触发后的默认行为
- 有人物参考图：以当前明确的人物图为唯一身份参考，保留五官辨识特征与体型，按 Skill 调整造型，默认换成冷白透粉闪光妆。只给一张清楚人物照时，默认它是身份图；多张人物且身份不明确时才澄清。不将纯服装图或无人场景图当作身份图。
- 无人物参考图：直接生成一位新的成年人物，默认冷白皮与完整招牌妆面，不索要身份图、不沿用之前案例中的人物脸。人物性别表达等未指定项可按当前语境决定。
- 默认妆面：明亮冷乳白底色透淡玫瑰红晕，粉色珠光眼影与银粉色细闪集中眼睑、内眼角及局部下眼缘，水润玫瑰唇；脸颈肩肤色协调，保留皮肤纹理。
- 默认表现：近轴闪光感、主体明亮背景较暗、上半身竖幅 3:4，以脸和眼妆为中心，突出皮肤光泽；画幅和衣着允许时自然展示锁骨，不为此改体型或强改用户指定衣服。
- 用户明确要求局部换妆并保留原造型时，才保留已有服装、背景和构图；其余有图或无图风格生成按所选配方使用目标摄影场景。按需读取冷白透粉配方。
- 用户明确指定其他肤色、妆容、光线、衣服或比例时，以当轮要求为准。只要求分析或提示词时不擅自生成图片；明确要求生成时应调用可用图像工具，而非只返回提示词。

## 先确定任务
区分三种输入：身份参考负责“是谁”；风格参考负责“怎么拍”；姿态参考负责“怎样摆”。同一张图可以承担多个角色，但应明确角色。只给风格图时，默认创作新的成年人物；需要保持特定人物时使用用户指定的身份图，不以文字承诺精确锁脸。没有图像输入能力时说明限制，不假称已分析。

先利用已有信息；只有身份来源、必须保留的服装或输出用途不明确且影响结果时才提问。输出比例、妆容强度等可给出明确默认值。

## 工作流
1. 查看图片，按主体、光影、色彩、妆容、动作接触、材质、构图记录观察。将可见事实与推断分开；不从照片断定真实年龄、人格、族裔或拍摄设备。
2. 提炼 3–5 条“关系规则”，并指出可替换的表面元素。首次分析本包来源图时读 [视觉分析](references/visual-analysis.md)。新参考应重新观察，不套用来源图结论。
3. 创建简短参数卡，明确身份、风格、姿态各自来源，按 [参数与模板](references/prompt-template.md) 组织提示词。
4. 选一种主光、一个主动作、一个主视觉中心。脸和手可形成主次，但不要让眼妆、首饰、背景同时争抢注意力。
5. 使用当前环境已提供且适合的图像工具；本 Skill 不假定特定 API 或插件。只要求提示词时交付提示词；要求生成时才执行生成。不要自行安装工具、调用付费外部服务或发布内容。
6. 按 [质量检查](references/quality-check.md) 检查实际结果；看不到结果则标为未检查。每轮围绕最严重问题改动一组变量，保留已通过的身份、光线与构图。

## 已验收风格：冷白透粉闪光妆

用户要求冷白底妆、淡红晕、眼周细闪、突出锁骨与皮肤时，读 [冷白透粉配方](references/porcelain-rose-flash.md)。这是默认妆面模式；保留身份与骨相，默认使用冷白透粉底色，用户明确要求其他妆面时覆盖默认。

## 必须保持的判断
- 身份优先于美化：保留眼距、眼型、鼻翼、唇形、下颌和不对称特征；不要以放大眼睛、缩鼻、削脸、未经要求提亮肤色替代摄影质感。
- 光线必须能解释脸、手、衣料、首饰和背景的明暗；局部光泽不等于全脸油亮。
- 先写清手部空间关系，再写美甲与戒指。遮挡不要求所有手指可见，但每个可见手指都应可追溯到对应手掌。
- 材质通过反光尺度、纹理与受力区别：皮肤细碎起伏、针织漫反射、金属小而亮、唇釉连续湿润反射。
- 镜头、光圈、色温数字仅可作创作意图或实拍起点；未经验证不得写成原图事实或保证模型遵循。
- 不使用“完美脸”“无瑕皮肤”等容易抹平身份与纹理的笼统词。

## 输出约定
默认中文解释；生成提示词可按工具习惯使用英文。交付：视觉关系摘要、参数卡、可直接使用的正向提示词、工具支持时的负面提示词、待检查项。用户只要其中一部分时缩减输出。

需要跨人物/场景改写时读 [完整示例](references/examples.md)。复杂手势、材质与布光的操作准则在 [摄影决策](references/photography-decisions.md)。文件包安装与范围见 [使用说明](USAGE.md)。

## 已认可的可选变体

用户要求柔雾底妆、连鼻玫粉腮红或黑底触唇近景时，可读 [玫粉柔雾黑底近景](references/rose-pink-velvet-closeup.md)。保留柔淡、浓郁两版；无图生成与一次近景身份参考两宫格获用户认可。按本人五官加强眉眼和唇部修饰，不仅叠加粉色；不替换默认配方。
