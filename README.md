# 妆容与穿搭研究 Skills

用于研究参考图、提炼可迁移配方、固定人物生成或编辑，并检查实际结果。

根据妆效意图识别：在人物妆容、写真或修图语境下，提到冷白皮、冷白透粉、白里透红、布灵布灵、bling bling、珠光眼妆或眼周细闪等效果时使用妆容 Skill；有人物参考图就只提取脸部辨识特征，由 Skill 主导妆容、发型、神态动作、服装配饰、场景、构图、光线与后期，无图就生成新的冷白皮成年人物。招牌效果是冷白透粉底色、眼周细闪、水润唇与鲜明皮肤光泽；用户当轮明确要求可覆盖默认。泛泛的人像生成请求不触发本 Skill；珠宝、服装等对象的闪光描述也不触发妆容流程。

## 使用

默认生成独立单张成片；宫格仅是历史验收的比较方式，不是 Skill 约束。多个风格版本可分别选用，不要求同时生成；多张默认分别交付，仅当用户明确要求时拼成宫格。

让助手读取所需目录的 `SKILL.md`，再提供身份图、风格图和本轮目标。可将两个顶层目录分别复制到所用客户端的技能目录。妆容目录内的案例通过相对路径按需读取；若要独立调用该案例，也可将其单独复制到技能目录。

不包含人物照片、账户配置或模型权重。冷白透粉风格已在一次指定人物编辑中获得用户认可；跨人物、跨模型的稳定性尚未验证。玫瑰棕四版完整造型已在一次有身份图四宫格中获得用户认可，涵盖妆容、配饰、穿搭与神态；跨人物、跨模型稳定性未验证。

## 持续学习参考图

支持研究新妆容、穿搭与耳环、项链、戒指、美甲等配饰：观察参考图，区分事实与推断，提炼色彩、尺度、留白、材质和反光的关系，再保存独立风格卡。仅分析、已试图与用户认可分别记录；新案例进入可选配方库；未指定风格时先分析人物，再分部位组合精致妆，不设固定默认妆容。
