# 妆容与穿搭研究 Skills

用于研究参考图、提炼可迁移配方、固定人物生成或编辑，并检查实际结果。

根据妆效意图识别：在人物妆容、写真或修图语境下，提到冷白皮、冷白透粉、白里透红、布灵布灵、bling bling、珠光眼妆或眼周细闪等效果时使用妆容 Skill；有人物参考图就保留身份换妆，无图就生成新的冷白皮成年人物。招牌效果是冷白透粉底色、眼周细闪、水润唇与鲜明皮肤光泽；用户当轮明确要求可覆盖默认。泛泛的人像生成请求不触发本 Skill；珠宝、服装等对象的闪光描述也不触发妆容流程。

## 使用

让助手读取所需目录的 `SKILL.md`，再提供身份图、风格图和本轮目标。可将两个顶层目录分别复制到所用客户端的技能目录。妆容目录内的案例通过相对路径按需读取；若要独立调用该案例，也可将其单独复制到技能目录。

不包含人物照片、账户配置或模型权重。冷白透粉风格已在一次指定人物编辑中获得用户认可；跨人物、跨模型的稳定性尚未验证。穿搭研究流程尚未单独生图验收。

## 持续学习参考图

支持研究新妆容、穿搭与耳环、项链、戒指、美甲等配饰：观察参考图，区分事实与推断，提炼色彩、尺度、留白、材质和反光的关系，再保存独立风格卡。仅分析、已试图与用户认可分别记录；新案例不会自动覆盖旧案例或招牌默认。

- [妆容与美甲的参考图学习流程](makeup-research/references/reference-learning.md)
- [穿搭与配饰的参考图学习流程](outfit-research/references/reference-learning.md)

例如：“研究这张妆容并沉淀成新配方”“提炼这对耳环与领口的关系”“根据这次反馈更新刚才的风格”。只要求分析时不自动生成图片或修改仓库；要求沉淀时按对应流程更新文件。
